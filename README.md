# Sistem-Piutang-Usaha-dan-Pembayaran-Pelanggan-pada-Distributor-Bahan-Bangunan
Sistem ini mencatat piutang usaha dan pembayaran pelanggan pada distributor bahan bangunan untuk membantu mengelola data pelanggan, invoice kredit, pembayaran piutang, status pelunasan, aging piutang, batas kredit pelanggan, serta laporan piutang.
